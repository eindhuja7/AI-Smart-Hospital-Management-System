# AI Smart Hospital Management System

## About the Project

AI Smart Hospital Management System is a web-based application developed to simplify hospital management activities.

The system helps manage patients, doctors, appointments and basic AI-based disease prediction.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- AI-based Disease Prediction
- Patient Registration
- Doctor Registration
- Hospital Dashboard
- MySQL Database Integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL
